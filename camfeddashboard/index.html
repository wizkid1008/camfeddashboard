How to Use This Dashboard

Use the filters above to explore dashboard data by level, sublevel, year, and country.

1
Select a Data Level Choose a programme level from the Level dropdown above.
2
Select a SubLevel Narrow down to a specific area within your selected level.
3
Select the Year(s) Use the date range slider. Move both ends to the same year for a single-year view.
4
Select a Country Filter by a specific country or view all countries together.
→ For school and district level data, click Dynamic Data in the upper right-hand corner.

    How to Use Dynamic Data

    Drill into country, district, and school-level data for any metric across any year range.

    1
    Select a Country Choose from the Country dropdown in the filter bar above to load district data.
    2
    Narrow to a District Once a country is selected the District dropdown activates — pick a district for district-level metrics.
    3
    Drill to a School Optionally select a specific school for the most granular, school-level view.
    4
    Set the Year Range Use the date sliders to view a single year snapshot or a multi-year trend across all metrics.
    → Charts automatically switch between single-year and multi-year views based on your date range selection.

    How to Use the Slicer

    Build a custom cross-geography analysis — combine any metrics, geographies, gender filter, and chart type.

    1
    Filter Geography Use the Countries, Districts, and Schools dropdowns to narrow your scope. Leave all unchecked to include everything.
    2
    Pick KPIs Select up to 8 metrics from the checklist above to compare side by side.
    3
    Filter by Gender Choose All, Female, or Male to segment results — the data is split 52 % female / 48 % male.
    4
    Choose a Chart Type Select Number, Line, Bar, Pie, Multi-Line, or Table to control how the output is visualised.
    → Set a year range first — the Slicer shows trends for every selected KPI across the years you choose.
